About the Project

System Architecture, Features & Implementation Details

Student Performance Analysis (SPA) System

The Student Performance Analysis (SPA) platform is an end-to-end academic analytics solution designed to ingest, clean, evaluate, and monitor student academic progression and institutional performance indicators.

By combining real-time database queries with analytical heuristics and visual dashboards, the system allows educators, counselors, and department heads to identify at-risk students early, recognize top performers, and tailor pedagogical interventions.

Core System Modules
Analytics Dashboard

Interactive visual charts for department, semester, subject, and gender trends powered by Chart.js.

ETL & Data Cleaning

Automated CSV schema validation, null value imputations, range clamping, and grade recalculation.

Risk Stratification

Dual-threshold risk matrix evaluating attendance shortages and exam failures to flag high-risk students.

Audit Reporting

Automated publication-ready PDF and CSV generation with ReportLab tables, statistics, and metadata.

Technology Stack
  • Backend Python 3.14 / Flask 3.1
  • Database SQLite 3
  • Data Processing Pandas 3.0
  • PDF Engine ReportLab 5.0
  • UI Framework Bootstrap 5.3
  • Charts Chart.js 4.4
Architecture Pattern Modular MVC (Model-View-Controller) with RESTful JSON endpoints
